# Meowy Self Panel (Python)

پنل وب فارسی برای سلف اکانت تلگرام: تغییر زمان‌بندی‌شده بیو، منشی خودکار و پاسخ هوشمند اختیاری.

## هشدار مهم
- این پروژه از اکانت شخصی تلگرام استفاده می‌کند و با API رسمی بات‌تلگرام یکی نیست.
- اتوماسیون بیش از حد ممکن است محدودیت یا مسدودشدن اکانت ایجاد کند؛ از پیام‌دادن انبوه/اسپم استفاده نکن.
- هرگز `TG_SESSION_STRING`، رمز پنل یا `OPENAI_API_KEY` را در GitHub منتشر نکن.
- این نسخه‌ی اولیه تنظیمات و قوانین کلیدواژه را در حافظه نگه می‌دارد؛ بعد از restart ممکن است از بین بروند.
- محدودیت بیوی تلگرام ممکن است بسته به نوع اکانت تغییر کند؛ کد متن را به ۷۰ کاراکتر محدود می‌کند.

## 1) ساخت API تلگرام
1. وارد https://my.telegram.org شو.
2. به API development tools برو و `api_id` و `api_hash` بگیر.

## 2) ساخت Session String (روی کامپیوتر یا Pydroid)
در محیطی امن، `pip install telethon` را اجرا کن و فایل `generate_session.py` را اجرا کن.
کد ورود تلگرام را وارد کن. خروجی `TG_SESSION_STRING` مثل رمز اکانت محرمانه است؛ در چت یا GitHub نفرست.

## 3) انتشار در GitHub
محتویات این پوشه را در یک مخزن خصوصی یا عمومی GitHub بارگذاری کن. فایل‌های `.env` و session نباید آپلود شوند.

## 4) استقرار روی Railway
1. در Railway یک پروژه بساز و Deploy from GitHub Repo را انتخاب کن.
2. در Variables این مقادیر را تنظیم کن:
   - `FLASK_SECRET_KEY`: یک رشته تصادفی طولانی
   - `PANEL_USERNAME`: نام کاربری دلخواه
   - `PANEL_PASSWORD`: رمز قوی پنل
   - `TG_API_ID`: api_id
   - `TG_API_HASH`: api_hash
   - `TG_SESSION_STRING`: session string تولیدشده
   - `TIMEZONE`: `Asia/Tehran`
   - `OPENAI_API_KEY`: اختیاری؛ فقط اگر پاسخ هوشمند می‌خواهی
   - `OPENAI_MODEL`: اختیاری؛ پیش‌فرض `gpt-4.1-mini`
3. Railway باید پورت را از متغیر `PORT` به برنامه بدهد؛ Procfile تنظیم شده است.
4. دامنه عمومی Railway را فعال کن و فقط از طریق HTTPS وارد پنل شو.

## 5) ورود به پنل
آدرس دامنه Railway را باز کن. با `PANEL_USERNAME` و `PANEL_PASSWORD` وارد شو.

## اجرای محلی
```bash
pip install -r requirements.txt
python generate_session.py
```
سپس متغیرهای محیطی را تنظیم کن و اجرا:
```bash
python app.py
```

## محدودیت‌های نسخه اول
- قوانین کلیدواژه و فرم پنل با restart پاک می‌شوند.
- اگر Railway سرویس را متوقف کند، زمان‌بندی اجرا نمی‌شود.
- هوش مصنوعی به کلید API و هزینه‌ی جداگانه نیاز دارد.
- برای استفاده واقعی بهتر است ذخیره‌سازی پایدار (SQLite) و محدودسازی تلاش‌های ورود اضافه شود.
